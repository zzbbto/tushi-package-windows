# 视频转场提示词生成器

为任何 AI 视频模型生成转场提示词的通用引擎。核心原则：**模型无关、类型无关、输入无关**。

## 通用工作流

无论输入是什么，按以下顺序处理：

1. **解析输入，补齐场景序列**

- 用户给完整脚本 → 提取场景列表
- 用户给场景列表 → 直接用
- 用户只给主题 → 主动设计 3-5 个合理场景序列
- 用户给已有提示词 → 按改写规则优化

2. **确定转场位置与数量**：每个场景衔接处一个转场；根据总时长定密度（一般 1 分钟内 2-4 个）
3. **为每个转场选类型**：按下方"选型指引"
4. **逐条撰写**：万能公式 + 画面化改写规则
5. **按输出格式交付 + 自检**

## 万能公式

> 【动作触发】+【遮挡/模糊过渡】+【新场景衔接】+【镜头质感】

## 画面化改写规则（关键，通用）

视频模型对"画面描述型"语言响应更好，避免抽象说明：

| 原则 | 坏例子 | 好例子 |
| --- | --- | --- |
| 具体画面元素 | "切换到新场景" | "街景变成暖黄灯光的咖啡馆内" |
| 写清光线/色彩变化 | "氛围变化" | "光影从暖黄变为幽蓝" |
| 节奏词引导运动速度 | "转场" | "镜头缓缓推近 / 猛然甩动" |
| 明确遮挡的物理完成态 | "短暂遮挡" | "前景人影完全覆盖画面变成全黑" |
| 可用英文衔接词 | — | seamless transition / revealed |
| 一条提示词只写一个转场 | 两个动作堆叠 | 拆成两条 |

## 转场选型指引

先确定转场目的，再选类型。全部类型的标准写法和提示词库见 [prompt-library.md](prompt-library.md)，按需读取对应段落。

| 目的 | 推荐类型 | 适用气质 |
| --- | --- | --- |
| 自然衔接、叙事流畅 | 遮挡、匹配、闪白 | 日常、纪实、剧情 |
| 视觉创意、电影感 | 相似动作、画中画、动态推拉、缩放穿越 | 广告、剧情、艺术 |
| 节奏卡点、情绪反差 | 硬切反差、相似动作、时间跳切 | 变装、混剪、卡点 |
| 时间流逝、空间跳跃 | 同机位跳切、开门/掀帘、旋转 | 旅行、剧情 |
| 蒙太奇、快速叙事 | 同类连用（见下） | 预告片、合集 |

## 多转场编排原则（一支视频多个转场时）

- **节奏曲线**：开场 1 个亮眼的抓注意力 → 中段轻量保流畅 → 高潮/结尾反差炸点
- **同类连用**：完全可以，遵循"形式统一、内容变化"——转场动作一致，每次切换的场景/情绪有递进或反差。适用于卡点蒙太奇、快速叙事段落。避免的只是"无意义重复"。正常叙事节奏下同类型隔 1-2 个其他类型更保险
- **复杂度递减**：激烈转场（甩镜、旋转）后接静态温和的（黑场、颜色匹配）做缓冲（同类型连用段落除外）
- **首尾呼应**：首尾转场可形成镜像，增强完整感
- **叙事优先**：每个转场都要有叙事/情绪理由，不为转场而转场

## 输出格式

- 按"转场 1、转场 2……"编号逐条输出，每条可直接独立粘贴
- 多转场时附一句编排逻辑说明（节奏设计、类型搭配）
- 用户要求其他格式（表格、分镜脚本、中英对照）时从之

## 交付前自检清单

单条：

- [ ] 只含一个转场动作
- [ ] 明确遮挡完全覆盖画面的瞬间（如适用）
- [ ] 前后场景光线/色调衔接合理
- [ ] 运镜方向一致，无穿帮
- [ ] 有节奏词（缓缓/快速/猛然/匀速）
- [ ] 可直接粘贴使用

多转场：

- [ ] 同类连用时"形式统一、内容变化"
- [ ] 激烈转场后有缓冲（连用段落除外）
- [ ] 开场有记忆点、高潮有炸点
- [ ] 数量与时长匹配
